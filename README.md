# Отрыв поручня метро

Интерактивная 3D-модель (Three.js, один файл `index.html`): человек держится одной рукой за вертикальный поручень в вагоне типа 81-717 при торможении поезда. Считаются сила руки, реакции и нагрузки на крепления к полу и потолку, срыв руки и отрыв крепления.

Запуск: открыть `index.html` в браузере (нужен интернет для Three.js с jsDelivr).

Регулируются: скорость поезда, замедление и время его нарастания (резкость), высота хвата, положение человека относительно поручня, масса, рост, устойчивость на ногах, сила хвата, число людей на поручне, тип заделки и прочность креплений.

Модель: тело — перевёрнутый маятник вокруг стоп, рука — пружина с демпфером, поручень — балка с шарнирными или жёсткими концами. Подробности — в разделе «Как считается» на странице.
